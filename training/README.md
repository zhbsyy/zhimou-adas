# 模型训练与部署转换

系统使用YOLOv8n目标检测和R15道路分割两条训练路线，最终通过RKNN INT8模型在RK3568运行。

|训练模块|源码与材料|
|---|---|
|[YOLOv8n 11类检测](object_detection/README_zh.md)|正式训练入口、类别覆盖/UNKNOWN监督、旧类保护、数据配置及参考导出|
|[R15道路分割](lane_detection/README_zh.md)|三阶段训练快照、配置、数据清单、评估、初始化材料及转换工具|

训练代码用于说明模型结构、监督方法和优化过程。原始数据集与部分早期初始化输入不随仓库提供；各模块说明列出恢复条件。部署运行直接使用`models`中的RKNN，不要求在设备上重新训练。
