# 系统运行条件

|子系统|运行条件|可观察状态|
|---|---|---|
|PCIe采集|加载匹配位流，设备BAR映射有效，驱动与内核匹配|采集帧持续更新|
|USB视频|设备端口与Front/Rear/Left/Right角色配置一致|四路画面方向和色彩正确|
|NPU推理|RKNN Runtime与模型平台匹配，模型和类别表完整|检测框、前视掩膜及推理状态更新|
|视频通信|PC/RK地址及服务端口一致，网络可达|总控台接收对应模式的视频|
|CARLA交互|引擎与Python API版本匹配，车辆控制会话唯一|车辆、相机与导航状态更新|
|座舱通信|串口115200、8N1，端口选择与设备一致|目的地、挡位等消息到达PC|
|离线处理|输入视频可解码，输出分区空间充足|MP4与摘要记录实际处理范围|

源图、感知结果、规则状态和车辆反馈是不同层次的输出。定位运行状态时，按输入、推理、通信和执行四个环节读取相应日志。模型前向频率、视频发布频率及界面刷新频率分别计量。

实时模式通过最新帧队列控制积压；离线模式按源帧顺序处理。设备和场景条件影响实际性能，帧率目标不代替板端实测。
