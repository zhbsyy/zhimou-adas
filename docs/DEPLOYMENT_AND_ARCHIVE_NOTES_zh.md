# 部署方案与模块边界

## 部署单元

|部署端|运行内容|外部依赖|
|---|---|---|
|Windows PC|总控台、CARLA客户端与车辆反馈|Python、CARLA引擎及相匹配的Python API|
|RK3568|视频输入、NPU推理、灯色/规则、编码与通信|ARM Linux、NPU Runtime、PCIe驱动、MPP/RGA/GStreamer|
|PG2L50H / PGL50H|双目与级联视频逻辑|板卡、传感器、PDS及下载接口|
|Android座舱|导航、串口报文和挡位联动接口|Android系统、串口访问权限|

仓库目录可以独立部署。`.runtime`由布局配置生成，`results`保存运行结果，模型统一位于`models`。源码与运行输出分离，便于模块维护和场景切换。

## 提交内容

提交硬件源码及位流、业务程序、两份部署RKNN、模型训练与转换材料、配置和技术文档。原始训练数据、已安装环境、操作系统与CARLA引擎由使用环境提供。独立倒车影像App属于外部应用，不在源码提交范围；座舱保留其调用接口。

部分原运行布局引用固定自检视频，视频作为外部素材按布局指定路径提供。实际模式的阈值、相机映射和通信参数保持各自配置，不合并为一个统一阈值。

原始验证资料与第三方来源集中在`verification`和各组件许可文件中，作品说明与原始来源资料分开维护。
