# 工程组成与复现范围

## 组成

- **硬件工程**：单板双目、双板级联接收与SFP发送设计，包含RTL、IP、约束及位流。
- **边缘感知**：目标检测、车道线分割、灯色分析、双目匹配与道路状态处理。
- **交互软件**：PC总控台、Android导航通信、CARLA车辆和场景控制。
- **模型材料**：YOLOv8n和R15的训练源码、配置、部署模型及转换工具。
- **验证材料**：软件接口、硬件构建、部分实板链路与仿真反馈记录。

## 复现条件

部署现有模型需要匹配的板端驱动、Runtime和媒体库；重新训练需要各训练清单所指向的原始图像、掩膜或检测标签及初始化权重。训练清单保留来源身份，迁移数据后需同步更新输入路径。

YOLO原A训练环境与历史参考导出vendor分开使用。R15训练分三个主阶段，最后阶段的选中权重用于后续部署导出。原A原始Ubuntu转换记录未收录，部署复现使用仓库中的RKNN；重新编译得到的文件需独立评价。

独立倒车影像App的源码和APK不提交。相关挡位调用作为座舱外部接口保留，物理四路视频功能由RK与PC模块实现。
