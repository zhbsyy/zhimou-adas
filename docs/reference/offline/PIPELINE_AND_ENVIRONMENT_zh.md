# 离线处理流水线

处理顺序为：视频解码→原始BGR帧→检测640×640→R15输入256×448→结果融合与绘制→MP4与JSON。

离线程序按源帧顺序执行，不使用实时模式的最新帧丢弃策略。结果时长与源帧计数共同记录，结束原因区分源文件结束、片段上限、解码故障、空间不足和中断。输出不保留音轨。

程序位于`software/rk3568/fusion/process_video_r15_offline.py`及模式专用前后处理模块，使用两份部署RKNN。输入视频和系统媒体库由运行环境提供。
