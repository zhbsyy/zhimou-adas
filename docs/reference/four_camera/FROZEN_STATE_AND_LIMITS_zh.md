# 四路模式配置与验证结果

|项目|参数|
|---|---|
|检测|四宫格一次640×640前向；class10为0.40，其他类别0.25|
|分割|Front独有，256×448 uint8 NHWC，阈值0.60|
|USB输入配置|320×240 MJPG，30FPS请求值|
|PCIe读取|按行读取，CAP_DELAY=40μs|
|视频输出|1280×720，MPP JPEG质量85，默认8083|

历史短时采样中，PCIe主机抓取约15.8–16.0FPS，检测约7.2–7.4Hz，R15约6.6–6.8Hz，JPEG发布约20FPS。这些窗口来自较早class10=0.60状态，不作为当前0.40策略的重新实测，也不作为长期性能保证。合成图可随USB更新，显示频率不等于FPGA新帧频率。

已保存的功能材料覆盖四路画面、颜色绑定、模型接口、状态发布及软件回归。FPGA原始报告仍有跨时钟约束问题，位流构建成功与完整时序签核分开记录。

该模式提供观察与感知，不执行座舱导航或CARLA行驶控制。证据索引见[系统验证](../../../verification/README.md)。
