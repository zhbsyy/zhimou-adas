# 物理四路道路观察

系统将前后双目与左右USB画面合成为四宫格，提供周边道路目标和前视车道结构的统一显示。PGL50H负责后向发送，PG2L50H负责本地与级联图像接收，RK接入侧向USB视频并执行视觉处理。

四宫格整体缩放后执行一次640×640检测，前视单独执行256×448分割。RK完成结果叠加和JPEG发布，PC总控台解码显示；该模式不发送导航或AEB控制指令。

实现入口为`software/rk3568/fusion/quad_infer.py`，用户启动入口为`scripts/rk3568/START_FOUR_CAMERA.sh`。摄像头角色、颜色参数与位流输出顺序配套。
