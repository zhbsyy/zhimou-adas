# 导航感知数据流与控制协议

Android导航消息经串口进入PC；PC依据地图与目的地执行路线，并采集CARLA四相机。四宫格通过视频服务输入RK，RK完成检测与Front分割，将标注视频和状态报告返回PC。

检测输入640×640，前视分割256×448，显示四宫格1280×720。检测与分割共享NPU访问锁，采集、显示及JPEG发布分离。队列优先保留最新帧，图像输入与叠加输出采用独立缓冲。

协议`carla_nav_aeb.control.v3`传输场景、行人关联和控制状态。距离与投影来自CARLA场景几何，RK的person检测提供视觉关联条件；PC负责制动执行、通过确认、路线恢复与驻车。

MPP/RGA承担媒体解码与格式转换，模型缩放和后处理仍包含CPU工作。运行状态分别统计模型与视频频率，不将缓冲复用描述为端到端零复制。
