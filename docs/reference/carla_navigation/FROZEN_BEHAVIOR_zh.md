# 仿真控制参数

|项目|配置|
|---|---|
|模型|检测640×640，Front分割256×448|
|候选阈值|class10为0.30，其他普通类别0.25；person AEB关联至少0.40|
|AEB导航速度|规划上限40km/h，服从目标速度、道路限速和终点减速|
|弯道与横穿|弯中≤15km/h；距横穿点18m时上限12km/h|
|横穿点|路线33%–67%区间内选择，优先中部|
|入场条件|7–13.5km/h，方向差≤12°，横向误差≤0.85m，对准≥0.35s，车头距点9–10.5m|
|视觉关联|连续≥2次person关联；前向0–30m，横向绝对值≤1.5m|
|制动条件|关联后距离<3.5m或TTC<2s|
|通过确认|停稳后同一行人正向clear证据≥5次且≥1s|
|报告迟到|持续≥2s进入需明确恢复的故障状态|

人工暂停、P挡、模式/AEB切换及新目的地进入明确的状态转换；碰撞需要重置或重新导航。PC按地图规划行驶，R15作为感知显示，不直接将掩膜转换为方向盘控制。

上述参数属于CARLA仿真场景。距离采用仿真几何，AEB要求RK视觉检测参与，不等同真实道路制动性能。
