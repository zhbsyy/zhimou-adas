# 导航会话与数据管理

导航状态分为目的地接收、路线执行、横穿等待、制动、通过确认、续行和到达驻车。AEB与人工操作通过控制仲裁组织，报告时效和碰撞状态参与恢复条件。

PC日志与事件位于`results/pc`，RK输出位于`results/rk3568/carla_navigation`。记录包括输入消息、感知关联、车辆执行与状态切换，可用于还原一次场景过程。

同一车辆控制会话由一个总控台管理；模型和采集程序按选定profile运行。代码维护遵循模块接口，网络、车辆控制与视觉模型分开定位。验证材料见[验证索引](../../../verification/README.md)。
