# 决策功能验证依据

|证据|覆盖内容|
|---|---|
|`verification/preserved_evidence/decision`|规则与软件验证、实板视频/状态、车辆反馈记录|
|`hardware/PG2L50H/verification/decision`|构建与时序资料|
|`tests/legacy_rk`、`tests/legacy_pc`|模块接口与反馈回归代码|

已有链路记录覆盖RK视频、CARLA前后车辆画面、停止请求、刹车灯状态及车身零位移。红绿灯全场景、全部边界和长期运行不由这一条链路记录替代。
