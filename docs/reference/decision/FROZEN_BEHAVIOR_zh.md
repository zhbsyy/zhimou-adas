# 决策模式参数与规则

|项目|配置|
|---|---|
|图像载荷|1280×720 RGB565；上半幅为左右目各640×360|
|模型输入|检测640×640；前视分割256×448|
|检测阈值|class10为0.50，普通类别0.25，灯候选0.15|
|R15阈值|0.60，planar argmax|
|输入RGB增益|0.916667、1.137931、0.970588|
|实时组织|采集、检测、分割、显示和编码分离；NPU共享锁，队列深度1|
|编码|MPP JPEG，质量85|

灯色在未绘制的交通灯候选区域内统计：红色H范围0–10或170–179，绿色40–95，S≥50、V≥60。绿色像素严格更多时选绿，否则选红；无灯框为unknown。像素比例作为颜色证据，不等同标定后的分类概率。

线型根据道路边界中已观察线段的长度加权计算虚线占比，达到40%判虚线，连续2次确认；边界不明或证据不足为unknown。

行人演示采用正前区域、置信度≥0.5及框高比例15%/25%/40%对应警告、减速和紧急制动，连续2次确认。风险解除使用新鲜无风险证据。车辆车身锁定，反馈体现为灯光、报警和前轮状态；人工灯光自检与视觉决策分别记录。

双目参数为参考标定，尚不能作为道路目标计量精度依据。拍摄屏幕时测量的是屏幕平面，行人风险比例为演示规则。
