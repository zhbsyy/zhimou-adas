# 决策模式软硬件接口

模式依赖PG2L50H单板双目位流、内核匹配的PCIe驱动、RKNN Runtime和媒体编码库。RK使用本地两份INT8模型、11类映射、相机颜色配置和参考双目参数。

PC接口包括规则摘要服务和处理后视频；车辆由CARLA提供可视化反馈。此模式不依赖座舱导航目的地或SFP发送板。

运行版本与驱动约束见[环境基线](../../../environment/README_zh.md)，位流角色见[硬件设计](../../../hardware/README_zh.md)。源码位置按仓库结构组织，由运行布局恢复内部相对导入。
