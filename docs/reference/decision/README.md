# 道路状态与静止车辆反馈

Decision模式以单板双目采集和RK道路感知为输入，将交通灯、线型、行人状态转化为可观察的车辆反馈。左目承担检测与分割，两目在后台参与参考匹配；PC车辆保持静止，展示灯光、前轮与报警状态。

|环节|实现|
|---|---|
|图像输入|PG2L50H本地双目、PCIe与MMIO32读帧|
|视觉处理|YOLOv8n检测、R15分割、灯色和道路边界分析|
|状态融合|行驶许可、越线约束、行人等级及图像时效|
|反馈展示|PC决策面板、车辆灯光和前轮状态|

核心代码为`software/rk3568/fusion/run_vision.py`及其通信、规则模块。PC通过状态服务接收判断结果，不重复执行同一套交通规则。
